# Liščí Dolina

2D plošinovka. Pět hrdinů, mince, hádanky a tajné úrovně.

**Úložiště:** https://github.com/32may/lisi-dolina

## Ovládání

- **A / ←** vlevo, **D / →** vpravo
- **W / ↑** skok
- **Mezerník** speciální schopnost
- **R** od začátku, **Esc** pauza

Začínáš s liškou. Mince z úrovní jdou do měšce a v obchodu po vlajce kupuješ další postavy.

Verze 2.0.
